# ArchAI

A simple terminal chatbot for Arch Linux support, package management, AUR help, and troubleshooting.

## Features

- chat in the terminal about Arch Linux
- provide AUR and pacman guidance
- support simple local command-based knowledge

## Usage

1. Open a terminal in `ArchAI`
2. Run `python3 archai.py`
3. Type your question and get an Arch-focused response

## Requirements

- Python 3.11+

## Notes

This is a basic local chatbot using keyword matching and short explanations. It is not an AI model, but it can be extended with external APIs or local large language models.
